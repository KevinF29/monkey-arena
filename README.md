# Monkey Arena

Roguelite 2D d'arène de gladiateurs : gagne ta liberté par le combat.

- 8 gladiateurs jouables : DarkKus, Fredhus, Sweevus, Chelmacus, Dridricus, Kubenicus, MaximusRr, Beel'Graalus
- Les 7 non choisis deviennent les boss de la run, dans un ordre aléatoire ; le dernier est couronné Empereur
- 7 actes de 5 combats + 1 boss (42 combats)
- Combats automatiques ; après chaque victoire, 1 récompense parmi 3 : équipement (7 emplacements) ou aptitude (5 au plus), chacun jusqu'au niveau 3, avec des bonus de panoplie
- L'équipement porté apparaît sur le gladiateur et dans l'inventaire sous le combat

Jouer : https://kevinf29.github.io/monkey-arena/
