# Monkey Arena

Roguelite 2D d'arène de gladiateurs : gagne ta liberté par le combat.

- 3 actes de 10 combats, un champion à la fin des actes I et II, l'Empereur Commode au combat 30
- Combats automatiques ; après chaque victoire, choisis 1 augment parmi 3 (arme, armure, aptitude)
- 3 gladiateurs jouables (à remplacer par les potes !)

## Jouer

Ouvre `index.html` dans un navigateur, ou va sur la page GitHub Pages du dépôt.
